Invitation Links

Create one reusable link per group of guests. Guests who open it see only the functions you choose.

How this works (tap to read)

You: choose the family, tick the functions, press Generate Invitation Link, press Copy Link and send it on WhatsApp. One link can go to as many guests as you like.

Guests: tap the link. The invitation opens and shows only the functions in that link. They never choose their side or functions. Their RSVP opens WhatsApp to the correct family's number.

Make a new link only when the group needs a different set of functions.

Who is signing in?

The secure link service is not set up on this site yet. You can still use basic links, but guests can edit these in their browser's address bar, so they are not tamper-proof. See the README to turn on signed links.

Basic mode. These links work, but a guest could edit the address to reveal other functions. Set up the Netlify Functions (README) for signed links.
